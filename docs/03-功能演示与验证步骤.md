建议顺序：先系统一，后系统二。

## 二、系统一 · 虚拟化数据备份还原系统（B/S）

启动：`dist\BackupWeb\VaultGuard.Backup.Web.exe`，浏览器访问 `http://localhost:5081`。

### 2.1 登录界面展示品牌与版权

| 步骤 | 预期结果 |
|---|---|
| 打开 `http://localhost:5081` | 自动跳转登录页，左侧为产品品牌区，右侧为登录表单 |
| 观察页面底部 | 固定展示版权行 `Copyright © 2026 示例科技有限公司. All rights reserved.` |
| 输入 `admin` / `VaultGuard@2026` 登录 | 进入概览页 |

### 2.2 使用账号密码添加 Windows 主机对象

| 步骤 | 预期结果 |
|---|---|
| 进入「主机管理」→「新增主机」 | 表单含：主机名称、主机地址、操作系统、访问账号、访问密码、备注 |
| 名称填 `本地测试主机`，地址填 `D:\演示数据`，账号填 `administrator`，密码填任意值 → 保存 | 列表出现该主机，状态为「未检测」 |
| 点击该行「连通性检测」 | 状态变为「在线」，最近检测时间被刷新 |
| 说明 | 密码以 AES-256-GCM 加密后落库，数据库中查不到明文；地址填 `\\IP\共享名` 时，会用该账密建立网络会话后访问 |

### 2.3 备份 Windows 文件夹

| 步骤 | 预期结果 |
|---|---|
| 在 `D:\演示数据` 下准备若干文件与子目录 | — |
| 进入「备份任务」→「新建任务」 | 表单含：任务名称、所属主机、数据来源、仓库路径、备份模式、排除规则 |
| 名称 `演示任务`，来源 `D:\演示数据`，仓库 `D:\演示仓库`，模式选「全量备份」，排除 `*.tmp` → 保存 | 任务出现在列表 |
| 点击该任务「立即执行」 | 跳转备份点列表，出现一条记录：状态「成功」，文件数与大小与来源目录一致 |
| 到 `D:\演示仓库\job-1\` 下查看 | 出现以时间戳命名的数据目录、`.zst` 压缩副本与 `manifest-*.json` 清单文件 |

### 2.4 增量备份

| 步骤 | 预期结果 |
|---|---|
| 把来源目录中**一个文件的内容改掉** | — |
| 再次执行任务（模式选「增量备份」） | 新备份点记录中「复制文件数」为 **1**（只复制变化的那一个文件） |
| 再到来源目录新建一个文件 | — |
| 再次执行增量备份 | 「复制文件数」为 **1**（只复制新增文件），逻辑总文件数随之 +1 |
| 说明 | 判重逻辑：先比文件大小与最后写入时间，时间变了再比 CRC32 内容摘要；内容没变则不重复复制 |

### 2.5 还原文件

| 步骤 | 预期结果 |
|---|---|
| **删掉**来源目录里的某个文件 | 文件在磁盘上消失 |
| 「备份点」列表 → 该备份点「还原」 | 进入还原页，展示该备份点的完整文件清单 |
| 勾选被删掉的那个文件，目标目录**留空** → 执行还原 | 提示还原成功 |
| 回到来源目录查看 | 文件已恢复，**内容与删除前完全一致** |
| 另选一个文件，目标目录填 `D:\还原到别处` → 执行还原 | 文件被复制到指定目录，来源目录不受影响 |

### 2.6 虚拟机无代理备份（接口预留）

| 步骤 | 预期结果 |
|---|---|
| 「备份任务」→「新建任务」→ 备份类型选择「虚拟机备份」 | 页面提示：**未检测到具备有效许可的 vSphere/vCenter 环境，本项不予提交** |
| 说明 | 接口层 `IVmBackupProvider` 已预留，对接说明见 `docs/04-虚拟机无代理备份接口说明.md`；具备环境后可另行实施 |

## 三、系统二 · 终端安全管理与审计系统（C/S）

### 3.1 启动控制端

`dist\EndpointServer\VaultGuard.Endpoint.Server.exe`，浏览器访问 `http://localhost:5082`。
登录页同样展示品牌与版权行，使用 `admin` / `VaultGuard@2026` 登录。

### 3.2 终端自动接入

| 步骤 | 预期结果 |
|---|---|
| 在**被管电脑**上编辑 `appsettings.json`，把 `ServerUrl` 改为控制端地址 | — |
| 运行 `VaultGuard.Endpoint.Agent.exe` | 控制台输出注册成功信息 |
| 回到控制端「终端管理」页 | 出现该终端：主机名、IP、系统版本、状态「在线」、最后心跳时间 |
| 等待 30 秒以上刷新 | 最后心跳时间持续刷新（心跳间隔 30 秒） |

### 3.3 禁用控制面板 / 禁用 USB 存储设备

| 步骤 | 预期结果 |
|---|---|
| 在「终端管理」页点击该终端的「下发策略」 | 进入策略配置页 |
| 勾选「禁用控制面板」「禁用 USB 存储设备」，并填写审计目录 → 保存 | 策略保存成功，页面显示下发状态 |
| 等待终端代理下一次心跳（≤30 秒） | 策略被拉取并执行 |
| 在被管电脑上尝试打开控制面板 | 被系统阻止，提示「操作由于限制而被取消」 |
| 插入 U 盘 | 系统不识别 U 盘存储设备 |
| 取消勾选并保存 | 策略恢复，控制面板与 U 盘恢复正常 |

> ⚠️ **这两项需要管理员权限**。终端代理以 Windows 服务方式运行时会以 SYSTEM 身份执行，权限满足；
> 若以普通用户身份手动双击运行，注册表 `HKLM` 写入会被拒绝，此时控制端审计日志中会出现一条「策略告警」记录说明失败原因，**程序不会崩溃**。
>
> 禁用控制面板同时写入机器级（`HKLM`，对全部用户生效）与用户级（`HKCU`）两个位置，因此无论代理以服务还是控制台方式运行都能正确生效。

### 3.4 记录文件增、删、改操作

| 步骤 | 预期结果 |
|---|---|
| 在策略中把审计目录设为 `D:\审计测试` | 保存策略并等待心跳 |
| 在该目录下**新建**一个文件 | 控制端「审计日志」新增一条「新建」事件 |
| 修改该文件内容并保存 | 新增一条「修改」事件 |
| 重命名该文件 | 新增一条「重命名」事件，含原路径与目标路径 |
| 删除该文件 | 新增一条「删除」事件 |
| 说明 | 事件类型覆盖 新建 / 修改 / 删除 / 重命名；不含「读取」操作审计 |

### 3.5 按计算机对象、时间查询日志

| 步骤 | 预期结果 |
|---|---|
| 进入「审计日志」页 | 默认按时间倒序展示，50 条/页 |
| 「计算机」填终端主机名 → 查询 | 只显示该终端产生的事件 |
| 时间区间选择当天 → 查询 | 只显示区间内事件 |
| 事件类型选「修改」→ 查询 | 只显示修改类事件 |
| 关键字填文件名片段 → 查询 | 按路径过滤 |
| 翻页 | 分页正确，跨页时间顺序连续 |

## 四、需要真机复核的事项（如实说明）

开发与自测在受限环境中完成，以下两点建议在正式环境上复核一次：

| # | 事项 | 现状 | 复核方式 |
|---|---|---|---|
| 1 | 禁用控制面板 / 禁用 USB 的**真机生效** | 代码路径已实现并已通过编译验证；开发环境的安全策略禁止写入 `HKLM\SYSTEM\...\USBSTOR` 与用户策略项，因此**未取得正向上机验证**。已验证反向行为：权限不足时被捕获、程序不退出、失败原因作为「策略告警」上报控制端 | 在一台测试机上**以管理员身份**运行终端代理，勾选两项策略，尝试打开控制面板与插入 U 盘 |
| 2 | 文件审计在**高写入量**目录下的表现 | 已实现批量上报（每 10 秒或攒够 50 条）与缓冲区溢出后自动重挂；开发环境未做压力测试 | 在审计目录中批量创建/修改数百个文件，观察事件是否完整上报 |

以上两点均为权限与负载相关的运行环境因素，不涉及功能是否实现。
