# 02 · 编译与部署说明

适用产品：虚拟化数据备份还原系统 V1.0 ／ 终端安全准入与行为审计系统 V1.0

---

## 一、环境要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11 / Windows Server 2016 及以上（64 位） |
| 开发环境 | .NET SDK 8.0 及以上 |
| 磁盘空间 | 源码编译约需 2 GB（含依赖缓存与发布产物） |
| 权限 | 终端代理如需禁用 USB 存储设备，需管理员权限 |
| 网络 | 首次编译需联网还原 NuGet 依赖；之后可离线编译 |

.NET SDK 下载地址：https://dotnet.microsoft.com/download/dotnet/8.0

验证环境是否就绪：

```bat
dotnet --version
```

输出 8.0.x 即表示就绪。

## 二、编译

### 方式一：一键编译（推荐）

双击工程根目录下的 **`build.bat`**，或在命令行执行：

```bat
build.bat
```

脚本依次完成：

1. 检查 .NET SDK 是否存在
2. `dotnet build VaultGuard.sln -c Release` 编译全部工程
3. `dotnet publish` 发布三套**自包含单文件**程序到 `dist\`

发布产物：

```
dist\
├─ BackupWeb\VaultGuard.Backup.Web.exe          系统一控制台（B/S）
├─ EndpointServer\VaultGuard.Endpoint.Server.exe 系统二控制端（C/S 服务端）
└─ EndpointAgent\VaultGuard.Endpoint.Agent.exe   系统二终端代理
```

自包含发布意味着**目标机器无需安装 .NET 运行时**，双击即可运行。

### 方式二：手动编译

```bat
dotnet restore VaultGuard.sln
dotnet build VaultGuard.sln -c Release
dotnet publish src\VaultGuard.Backup.Web\VaultGuard.Backup.Web.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o dist\BackupWeb
dotnet publish src\VaultGuard.Endpoint.Server\VaultGuard.Endpoint.Server.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o dist\EndpointServer
dotnet publish src\VaultGuard.Endpoint.Agent\VaultGuard.Endpoint.Agent.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o dist\EndpointAgent
```

### 方式三：开发调试（不发布）

```bat
dotnet run --project src\VaultGuard.Backup.Web     --urls http://localhost:5081
dotnet run --project src\VaultGuard.Endpoint.Server --urls http://localhost:5082
dotnet run --project src\VaultGuard.Endpoint.Agent
```

### 编译空间不足时的替代方案

若不使用自包含发布（例如目标机器已装 .NET 运行时），可去掉 `--self-contained true -r win-x64` 参数，改为**框架依赖发布**，产物体积由约 90 MB 降至约 2 MB：

```bat
dotnet publish src\VaultGuard.Backup.Web\VaultGuard.Backup.Web.csproj -c Release -o dist\BackupWeb
```

## 三、部署与启动

### 3.1 系统一 · 备份还原控制台（B/S）

1. 将 `dist\BackupWeb\` 整个目录拷贝到服务器
2. 双击 `VaultGuard.Backup.Web.exe`
3. 浏览器访问 `http://localhost:5081`
4. 使用默认账号登录：`admin` / `VaultGuard@2026`

> 默认监听 `0.0.0.0:5081`（所有网卡）。本机用 `http://localhost:5081`，局域网内其他电脑用 `http://服务器IP:5081` 访问；如需按域名或反向代理访问，走 `--urls` 指定即可。

如需修改监听端口：

```bat
VaultGuard.Backup.Web.exe --urls http://0.0.0.0:8081
```

### 3.2 系统二 · 终端管控控制端（C/S 服务端）

1. 将 `dist\EndpointServer\` 整个目录拷贝到服务器
2. 双击 `VaultGuard.Endpoint.Server.exe`
3. 浏览器访问 `http://localhost:5082`
4. 使用默认账号登录：`admin` / `VaultGuard@2026`

> 默认监听 `0.0.0.0:5082`（所有网卡），因为终端代理通常安装在**其他电脑**上，必须能跨机访问。请确保服务器防火墙放行 `TCP 5082` 入站。

### 3.3 系统二 · 终端代理（部署到被管电脑）

1. 将 `dist\EndpointAgent\` 整个目录拷贝到被管电脑
2. 修改同目录下 `appsettings.json`，把 `ServerUrl` 指向控制端地址：

```json
{
  "ServerUrl": "http://192.168.1.10:5082",
  "HostName": ""
}
```

3. 直接运行 `VaultGuard.Endpoint.Agent.exe`（控制台方式，便于观察日志）
4. 首次运行会自动向控制端注册，随后每 30 秒心跳一次，控制端「终端管理」页即可看到该终端

**注册为 Windows 服务（开机自启）**，以管理员身份执行：

```bat
sc create VaultGuardEndpointAgent binPath= "C:\路径\VaultGuard.Endpoint.Agent.exe" start= auto
sc start VaultGuardEndpointAgent
```

停止与删除服务：

```bat
sc stop VaultGuardEndpointAgent
sc delete VaultGuardEndpointAgent
```

> 提示：以 Windows 服务方式运行时，进程账号通常为 SYSTEM。**如需禁用 USB 存储设备，请确保服务以 LocalSystem 或管理员权限运行**，否则注册表 `HKLM` 写入会被拒绝，控制端审计日志中会出现相应的策略告警记录。

## 四、数据存放位置

程序首次运行会在**自身目录**下创建 `data` 子目录：

| 路径 | 说明 |
|---|---|
| `data\vaultguard-backup.db` | 系统一数据库（主机、任务、备份点、还原记录、操作日志） |
| `data\vaultguard-endpoint.db` | 系统二数据库（终端、策略、审计事件、操作日志） |
| `data\secret.key` | 主机凭据加密密钥（AES-256，32 字节） |
| `data\logs\` | 运行日志 |

> ⚠️ **`secret.key` 务必备份**。该文件用于加密主机访问密码，一旦丢失，数据库中已保存的密码将无法解密，需要重新录入。

### 数据备份建议

- 定期备份 `data\vaultguard-backup.db` 与 `data\secret.key`
- 备份仓库目录（任务中设置的「仓库路径」）是实际的数据副本，同样需要纳入备份

## 五、常见问题

| 现象 | 原因与处理 |
|---|---|
| 编译报 `error MSB3021 磁盘空间不足` | 磁盘剩余空间不足。清理磁盘，或改用框架依赖发布（见第二节） |
| `dotnet` 不是内部或外部命令 | 未安装 .NET SDK，或未加入 PATH。安装 SDK 后重开命令行 |
| 首次编译报 NuGet 还原失败 | 需要联网。无法联网时，可在一台联网机器上执行 `dotnet restore` 后拷贝 `~\.nuget\packages` 目录 |
| 浏览器打不开页面 | 端口被占用。换端口启动：`--urls http://localhost:5081` 改成其他端口 |
| 登录提示用户名或口令不正确 | 默认账号为 `admin` / `VaultGuard@2026`；数据库若被删除，重启程序会自动重建默认账号 |
| 终端代理收不到策略 / 控制端看不到终端 | 检查 `appsettings.json` 中的 `ServerUrl` 是否可达；检查防火墙是否放行控制端端口 |
| 策略显示「失败：拒绝访问」 | 终端代理权限不足。以管理员身份运行，或改用 LocalSystem 服务账号 |
| 主机「连通性检测」失败 | 远程主机的共享路径不可达，或账号密码错误。UNC 路径需形如 `\\IP\共享名` |

## 六、卸载

本产品为绿色部署，不含安装程序：

1. 停止正在运行的程序（或停止 `VaultGuardEndpointAgent` 服务并 `sc delete`）
2. 删除程序目录即可
3. 如需彻底清理终端策略，请在被管电脑上手工恢复注册表项：
   - `HKCU\Software\Microsoft\Windows\CurrentVersion\Policies\Explorer` 下的 `NoControlPanel`
   - `HKLM\SYSTEM\CurrentControlSet\Services\USBSTOR` 下的 `Start`（恢复为 3）
